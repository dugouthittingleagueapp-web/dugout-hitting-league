DUGOUT HITTING LEAGUE - OPERATIONAL GUIDE

1. GETTING STARTED & ROLES
   - FAN (Default): Read-only access. View scores, standings, and live games. No login required.
   - UMPIRE: Password required. Can start matches, score games, manage rosters, and edit history.
   - ADMIN: Password required. Full control including creating leagues, resetting seasons, and exporting data.
   * Note: Sessions expire after 3 hours of inactivity.

2. SETTING UP (Admin)
   - Create League: Use the Admin Dashboard to create categories (e.g., Varsity, 10u).
   - Team Rosters: Enter First Name (Display) and optional Last Name (Admin tracking).
   - Active Season: Admin can create and switch seasons (e.g., 2027, 2028, etc.) to archive old data and rollover clean brackets.

3. MATCH WORKFLOW
   - Log in as Umpire or Admin.
   - Select Home and Away teams on the Dashboard.
   - Click "Next: Set Lineup".
   - Drag to reorder players. Click "+ Add Sub" if needed.
   - Click "Start Match".

4. SCORING RULES
   - Entry: Tap a pitch box (1-10) and select score (0-4).
   - Auto-Advance: The inning tabs switch automatically when all pitches are recorded.
   - Undo: Use the "Undo Previous" button in the scoring modal to correct mistakes.
   - Edit: Tap any completed score to change it.

5. SHORT-HANDED TEAMS
   - 2v2 Matches: Standard scoring. 10 pitches per player. 20 Team Pitches total.
   - 3v2 Matches (Ghost Mode): The 2-player team gets 15 pitches each.
     * Pitches 1-10 count for the Player.
     * Pitches 11-15 count for the Team (Ghost Player).

6. TIE BREAKERS
   - If tied after 6 innings:
   1. Select one shooter from each team.
   2. Play Extra Innings (Round 1 = 5 pitches).
   3. Scores are added to team total and player stats.

7. ADMIN TOOLS
   - Move Match: Fix matches scored in the wrong league via the Dashboard "Move" button.
   - Bulk Move Teams: Move entire rosters and their history to a new league via Admin Dashboard.
   - Screen Wake Lock: The screen will stay awake automatically while viewing the live scoreboard on mobile/tablet.
