
DUGOUT HITTING LEAGUE - OPERATIONAL GUIDE
=========================================

1. GETTING STARTED & ROLES
--------------------------
The app has three levels of access. You log in via the "Log In" button in the top right corner (or via the menu on mobile).

A) FAN (Default - No Login Required)
   - Can view all Leagues.
   - Can view "Season Stats" and "Standings".
   - Can watch "Live" games (scores update automatically every 5 seconds).
   - CANNOT start games, edit scores, or change settings.

B) UMPIRE (Password: umpire)
   - Can Start Matches.
   - Can Score games.
   - Can Edit/Delete Match History.
   - Can Manage Teams (Add/Edit/Delete Rosters).
   - Can Update the Umpire Password in Admin settings.

C) ADMIN (Password: admin)
   - Has all Umpire permissions.
   - Can Create New Leagues (e.g., 9u, 10u, Varsity).
   - Can Change the "Active Season" (e.g., switching from 2025 to 2026).
   - Can Reset Passwords.
   - Can Export Data to JSON.

*Note: You can change these passwords in the "Admin" dashboard once logged in.*
*Security Note: For security, logged-in sessions (Umpire/Admin) will automatically expire after 3 hours of inactivity. You will need to log in again.*


2. SETTING UP A NEW SEASON
--------------------------
1. Log in as Admin.
2. Go to the "Admin" dashboard.
3. Create a League (if one doesn't exist, e.g., "Varsity").
4. Ensure "Active Season" is set to the current year (e.g., 2025).
5. Go back to the Dashboard.
6. Click "Manage Teams" to add team names and rosters (3 players default).


3. STARTING A MATCH
-------------------
1. Ensure you are logged in as Umpire or Admin.
2. Select a "Home Team" and "Away Team" from the dropdowns on the left.
3. Click "Next: Set Lineup".
4. Drag and drop players to set the batting order.
   - If a team only has 2 players present, remove the 3rd player here.
   - If a team has a Sub, click "+ Add Sub" to type in their name.
5. Click "Start Match".


4. SCORING RULES
----------------
- Click the score box (Pitch 1, 2, etc.) and select the points (0, 1, 2, 3, 4).
- Colors: 0=Grey, 1=Cyan, 2=Green, 3=Orange, 4=Red.
- UNDO: If you enter a score by mistake, open the scoring modal for the next pitch and click "Undo Previous" to clear the last entered score.
- LIVE EDITING: You can also click any previously scored box to edit it directly. Change the number and click "Update".

5. SHORT-HANDED TEAMS (2v2 & 3v2)
---------------------------------

2v2 MATCHES:
In a standard 2v2 match (both teams have 2 players), scoring works just like 3v3 but with fewer players.
- Each player gets 10 pitches per inning.
- Total Team Pitches per Inning: 20.
- No Ghost Player is used.

3v2 MATCHES (GHOST MODE):
If one team has 3 players and the other has 2, the 2-player team enters "Ghost Mode" to ensure they also get 30 total swings.
- Players 1 & 2 get 15 pitches each.
- Pitches 1-10 appear on the player's row.
- Pitches 11-15 automatically appear on the "Ghost Row" (Player 3).
- STATS: Only pitches 1-10 count towards the player's personal stats. Pitches 11-15 count towards the Team Total (attributed to "Player 3").

6. TIE BREAKERS (EXTRA INNINGS)
-------------------------------
If the score is tied after 6 innings:
1. A "Tie Game" modal will appear.
2. Select ONE shooter from the Home Team and ONE shooter from the Away Team.
3. The game enters Extra Innings (Inning 7+).
4. Round 1 is typically 5 pitches each. If still tied, subsequent rounds may have reduced pitch counts (3 or 1) until a winner is decided.
5. Tie-breaker points are added to the Team's total score and the individual player's match stats.

7. LATE ARRIVAL (RESETTING ROSTER)
----------------------------------
If a game starts with 2 players, but the 3rd player arrives late:

1. Wait for the start of a new inning (between Inning 2 and 6).
2. Look for the button "+ Reset Roster" next to the team name on the scoreboard header.
3. Click it and confirm.
4. The game effectively resets to "Normal Mode" (3 Players, 10 Pitches each) for the REMAINDER of the game.
5. Stats from that point forward will count for the individual players correctly.

8. MOBILE NAVIGATION
--------------------
- The app is optimized for mobile devices.
- Use the "Menu" button (top left) or the top navigation bar to switch between screens.
- Avoid using the browser's "Refresh" button during a live game to prevent losing unsaved local state (though matches are saved to the database after every pitch).
- In the Scoreboard, use the horizontal tabs to switch between innings.

9. STATISTICS
-------------
- STANDINGS: Shows Wins, Losses, Ties, Points For, Points Against.
- SEASON STATS: Shows individual leaderboards (Total Points, 4s, 3s, etc.). Note: Ghost player stats are filtered out of this list.
- MATCH STATS: Click "Stats" on any completed game card to see the box score for that specific game.
