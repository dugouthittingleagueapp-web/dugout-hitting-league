# Admin roster management — Preview only

Admin Dashboard now has Dashboard, Schedule, and Rosters tabs. Rosters uses the active season independently of the archive browser. Choose a league and team, edit names, add regular players (two or three total), add substitutes, and move existing players between the regular roster and substitutes. Existing members are retained so saved player IDs and game history remain resolvable. New unsaved rows can be removed.

Roster saves require server confirmation and retain drafts on failure. A source-roster comparison and team-row transaction serialize competing admins and reject stale edits. The server validates player identities, names, counts, and duplicates; it prevents archived-season changes and edits during in-progress games or open scoring sessions. Roster updates preserve recorded pitches, status, completion flags and previously selected nonempty lineups. Filling an imported team’s completely empty roster initializes only empty official SCHEDULED game templates and increments those game revisions; umpires choose attendance through Set Lineup.
